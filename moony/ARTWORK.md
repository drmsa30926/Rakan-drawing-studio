# Artwork provenance

All eight `art/*.jpg` landscape references were generated specifically for Moony
using OpenAI's built-in image generation tool on 7 October 2026. They are original
generated illustrations, not external photographs, not human-made drawings and
not asserted to be CC0/public-domain works. No artist name or copyrighted character
was used. No Unsplash, Pexels or unverified image download was used.

Common prompt: original realistic graphite pencil study for an adult drawing
course, landscape 3:2, neutral grayscale, visible layered hatching, paper tooth,
coherent light, natural selective edges; no vector look, airbrush, photograph,
text, signature, frame, hands or tools.

Subjects: mountains reflected in a lake; sweeping desert dunes; palm oasis;
forest path; sea cliffs; cumulus cloud; old oak; stone house in a valley.

Source PNGs were converted to grayscale JPEG at 1200×800 for offline delivery.
Analytical stage views are generated locally from these same references, so the
composition remains aligned. They must not be advertised as a filmed or authentic
manual step-by-step drawing demonstration. Original procedural canvas studies
are retained as educational diagrams/fallbacks.
